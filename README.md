# Python Computer Vision Projects

A collection of Python-based computer vision projects focused on real-time hand tracking, gesture recognition, face mesh detection, and virtual mouse interaction using a camera.

## Overview

This repository contains six individual projects that demonstrate practical applications of computer vision and human-computer interaction. The projects explore how camera input and visual tracking can be used to recognize hand movements, count fingers, control mouse actions, and detect facial landmarks.

## Projects Included

| No. | Project | Description |
|---|---|---|
| 1 | Camera Access | Accesses the camera and displays a real-time video feed using Python. |
| 2 | Hand Detection | Detects and tracks hands in real time using computer vision techniques. |
| 3 | Finger Counter | Identifies raised fingers using hand landmarks and gesture analysis. |
| 4 | Virtual Mouse | Enables mouse pointer control through hand gestures. |
| 5 | Virtual Mouse Click | Implements gesture-based clicking for touch-free computer interaction. |
| 6 | Face Mesh Detection | Detects facial landmarks to analyze facial structure and movement. |

## Technologies Used

- **Python** — Core programming language.
- **OpenCV** — Image processing and real-time camera handling.
- **MediaPipe** — Hand tracking, hand landmark detection, and facial mesh estimation.

*Note: The exact libraries and versions may vary depending on the implementation of each project.*

## Key Features

- Real-time camera access and video processing.
- Hand detection and landmark tracking.
- Finger counting through gesture recognition.
- Gesture-controlled mouse movement and clicking.
- Facial landmark detection using face mesh techniques.
- Practical exploration of computer vision and human-computer interaction.

## Getting Started

### Prerequisites

- Python installed on your system.
- A working webcam or camera.
- Required Python libraries for the selected project.

### Installation

1. Clone the repository:

   ```bash
   git clone <YOUR_REPOSITORY_URL>
   ```

2. Navigate to the project directory:

   ```bash
   cd <YOUR_PROJECT_FOLDER>
   ```

3. Install the dependencies required by your project:

   ```bash
   pip install opencv-python mediapipe
   ```

4. Run the desired Python file:

   ```bash
   python project1_camera.py
   ```

Replace the filename with the project you want to execute. If a project requires additional dependencies, install them before running it.
